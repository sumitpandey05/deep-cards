# Deep Cards Project Requirements ## Overview A two-player co-located card game web app (single device) inspired by "36 Questions That Lead to Love" and "We're Not Really Strangers." ## Target Experience - **Vibe:** Warm, intimate, minimal, ritualistic. - **Goal:** Progressive conversation (Level 1 -> 2 -> 3). - **Setup:** Shared age group selection, individual gender selection. ## Screen List 1. **Landing/Start:** Introduction to the ritual. 2. **Setup - Age Group:** Choose from Under 18, 18–24, 25–34, 35+. 3. **Setup - Gender:** Each player selects (Man, Woman, Non-binary, Prefer not to say). 4. **Game Loop:** Single card display, Level indicator, Progress bar, "Next Card" action. 5. **Closing:** A warm conclusion to the session. ## Visual Direction - Soft colors, generous typography, gentle animations. - Dark mode support. - No timers, scoring, or competitive elements. ## Tech Specs (for reference) - Next.js (React), JSON question bank, Static Vercel deployment, PWA support.
